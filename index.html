What Makes Seraph Different

🛡

Guardian Intelligence

Persistent identity via a soul file, long-term vector memory, and proactive insights — Seraph remembers, learns, and acts on your behalf.

🎮

RPG Interface

A Phaser 3 pixel-art village where your agent avatar walks between tool stations — forge, well, tower, mailbox — while you chat via an RPG dialog box.

🔧

Tool Ecosystem

Web search, file I/O, shell execution, email, calendar, browsing, and MCP integrations — all visualized as village buildings.

🌐

Open Source

Built with React, Phaser 3, FastAPI, and smolagents. Fully open, extensible, and ready to hack on.
